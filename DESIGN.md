## 4. Typography
- Headings font feel: _e.g., modern sans / elegant serif / rounded_
  - Modern sans _(e.g., Inter / IBM Plex Sans)_
- Body font feel:
  - Modern sans (same family as headings)
- Thai text needed? (affects font choice): 
  - English only by default; Thai is rare (occasional words/phrases)
  - Preferred Thai font: TH Sarabun New or Cordia New
    - Web note: use **Sarabun** (free on Google Fonts; web version of TH Sarabun New)
    - Avoid Cordia New on the web — Windows system font; can't be legally embedded, and Mac/phone visitors don't have it
    - Thai glyphs look smaller than Latin at the same size → bump Thai text size slightly (~1.1–1.2×)
    - Load the Thai font only on pages that use Thai (keeps the site fast)
